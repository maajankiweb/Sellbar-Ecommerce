## Phase 1: Homepage (`/`) Conversions & Trust Widgets

### 1.1 Hero Instant Valuation Widget (3-Click Quick Estimator)
- [ ] **Feature:** Hero section me floating glassmorphic card.
- **Details:**
  - Dropdown 1: Select Category (`Mobile Phone`, `Laptop`, `Smartwatch`, `Tablet`).
  - Dropdown 2: Select Brand (`Apple`, `Samsung`, `OnePlus`, etc.).
  - Dropdown 3: Select Model (`iPhone 14 128GB`, `Galaxy S23`, etc.).

### 2.1 Visual 4-Step Interactive Condition Diagnostics
- [x] **Feature:** Dropdown form ke badle interactive visual diagnostic cards. (Completed ✅)
- **Details:**
  - **Step 1: Screen Condition** (Flawless / Minor Micro-scratches / Cracked Glass / Touch Display Issue).
  - **Step 2: Body & Frame** (Zero Dents / Minor Edge Scratches / Heavy Dents / Bent Housing).

- [x] **Feature:** Dynamic animated countdown timer banner on quote generation. (Completed ✅)
- **Details:**
